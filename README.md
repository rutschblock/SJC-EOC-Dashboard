# San Juan County EOC Dashboard

Prototype EOC incident management dashboard for San Juan County, Colorado.

## Status
**PROTOTYPE — SIMULATED DATA.** Not an official active incident status display. Verify all information through approved operational channels before use.

## Contents
- `index.html` — Current dashboard prototype (Version 11 baseline)
- `archive/version-11.html` — Preserved Version 11 snapshot

## Publishing via GitHub Pages
In repository Settings > Pages, choose **Deploy from a branch**, branch **main**, folder **/(root)**. Save. The published URL will be `https://rutschblock.github.io/SJC-EOC-Dashboard/` if the repository is named `SJC-EOC-Dashboard` under the `rutschblock` account.

## Operational caution
This static prototype does not authenticate users or store operational changes centrally. Do not enter sensitive incident data or personally identifiable information. External service links are independent of this dashboard.
